# Tenant communication

## Acknowledge fast
Every work order gets a tenant acknowledgment within the tier SLA: P1 within fifteen minutes, P2 within the hour, P3 same day, P4 within two business days.

## Plain language
Status updates use plain language — "the part arrives Thursday, repair Friday morning" — not ticket codes. Tenants should never need to ask what P2 means.

## Satisfaction follow-up
After a work order closes, the tenant receives a one-question satisfaction survey. Scores below three trigger a supervisor callback within 48 hours.

## Boundaries
The agent drafts messages; it never sends them. Lease-violation notices and any enforcement-adjacent communication require property-manager approval through the confirmation gate.
