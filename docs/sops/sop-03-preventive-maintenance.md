# Preventive maintenance

## Schedule discipline
Preventive tasks have due dates, not suggestions. Elevator, boiler, and fire-alarm tasks that go overdue are escalated to the supervisor the same day they lapse.

## Parts lead time
Before scheduling a preventive task that needs parts, check the parts lead-time feed. If the live feed is unavailable, say so explicitly and use the seeded planning estimates — never quote a lead time you did not retrieve.

## Completion evidence
A preventive task is done only when the technician logs completion with a timestamp. A verbal "it's handled" does not close the task.

## Trending
Review overdue preventive tasks weekly. Two overdue tasks on the same asset in a quarter triggers a replacement-versus-repair review.
